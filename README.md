# Customer Behaviour Analysis

## Overview

This is an end-to-end **Data Analytics project** focused on analyzing customer behaviour, purchasing patterns, sales, revenue, subscription status, and customer demographics.

The project follows a complete data analytics workflow using **Python, SQL, MySQL, and Power BI**, along with a project report and presentation.

---

## Dataset

The dataset contains customer-related information such as:

- Customer ID
- Age
- Gender
- Category
- Purchase Amount
- Review Rating
- Subscription Status
- Shipping Type
- Frequency of Purchases
- Other customer behaviour attributes

---

## Tools & Technologies

- **Python** – Data cleaning and Exploratory Data Analysis (EDA)
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib & Seaborn** – Data visualization
- **MySQL** – SQL querying and data analysis
- **Power BI** – Interactive dashboard and visualization
- **Gamma** – Project presentation

---

## Project Steps

### 1. Data Exploration

- Loaded and explored the dataset using Python.
- Examined the dataset structure, columns, and data types.
- Generated summary statistics.
- Identified missing values and duplicate records.

### 2. Data Cleaning

The dataset was cleaned and prepared using Python and Pandas.

Key activities included:

- Handling missing values
- Removing duplicate records
- Checking and correcting data types
- Identifying inconsistent values
- Preparing data for analysis

### 3. Exploratory Data Analysis (EDA)

EDA was performed to understand customer behaviour and identify patterns.

The analysis included:

- Customer demographics
- Purchase behaviour
- Sales by category
- Revenue by category
- Subscription status
- Age-group analysis
- Customer ratings
- Purchasing frequency

### 4. SQL Analysis

The cleaned dataset was imported into **MySQL Server** for further analysis.

SQL queries were used for:

- Filtering data
- Aggregations
- GROUP BY analysis
- Sorting
- Conditional analysis
- Customer segmentation
- Sales analysis
- Revenue analysis

### 5. Power BI Dashboard

An interactive Power BI dashboard was created to visualize key insights.

The dashboard includes:

- Number of Customers
- Average Purchase Amount
- Average Review Rating
- Customer Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group

Interactive slicers were added for:

- Subscription Status
- Gender
- Category
- Shipping Type

### 6. Project Report

A detailed report was created covering:

- Dataset overview
- Data cleaning
- Exploratory Data Analysis
- SQL analysis
- Power BI dashboard
- Key findings
- Business insights

### 7. Presentation

A project presentation was created using **Gamma** to present the analysis, dashboard, findings, and business insights in a clear and structured format.
